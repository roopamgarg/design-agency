Accessibility Rules

WCAG 2.1 AA compliance baked into the token system from foundations.

Color Contrast
All text meets 4.5:1 contrast ratio (normal text) and 3:1 (large text). Primary text #1A1A1A on #FAF8F5 achieves 15.5:1.
Touch Targets
Minimum 44x44px for all interactive elements. Button heights are 36/44/52px with generous horizontal padding.
Reduced Motion
All transitions respect prefers-reduced-motion by reducing to 0ms. Animations are disabled entirely for users who prefer reduced motion.
Focus Indicators
All interactive elements show a 2px gold outline with 2px offset on :focus-visible. Never remove focus indicators.
Color Independence
Never use color alone to convey meaning. Error states combine red color + text message + icon. Status badges include text labels.
